# Nasaem Mobile V2

Android shell for the existing Nasaem customer platform.

## Strategy

The mobile app uses Capacitor as a native Android container while keeping the existing Next.js customer experience and backend as the source of truth.

Initial mode uses the deployed customer URL configured by `NASAEM_APP_URL`. This avoids duplicating business logic while the mobile-first V2 screens are developed.

## Local setup

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env` and set `NASAEM_APP_URL`.
3. Add Android once locally: `npm run android:add`
4. Sync native project: `npm run sync`
5. Open Android Studio: `npm run android:open`

The Android project generated by Capacitor is intentionally created from this package. CI will build an APK once the native Android project is committed.
