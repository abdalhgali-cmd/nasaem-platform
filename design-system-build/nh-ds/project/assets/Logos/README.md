# Logos

Official files, extracted from the brand logo PDF (transparent PNG):

- **nasaem-logo-horizontal.png**: emblem + wordmark side by side, for light grounds. Headers, login, documents.
- **nasaem-logo-horizontal-dark.png**: the same with the navy parts white, for navy or dark grounds.
- **nasaem-logo-stacked.png** / **nasaem-logo-stacked-dark.png**: emblem above wordmark, for square spaces.
- **nasaem-emblem.png**: the emblem alone (Kaaba, navy orbit, plane, gold arc). Admin sidebar tile, favicon, app icon. Its orbit gap is transparent: place it on white.

Older website files (white background, from `web/public/`), kept until the site is updated:

- **nasaem-logo.png**, **nasaem-logo-dark.png**, **nasaem-mark.png** (a crop of the old file).

Colours in the artwork: navy `#2E3792`, gold `#FAB60D`, charcoal `#3A3637`. Never recolour, stretch, add shadows, or place the light lockup on navy.
