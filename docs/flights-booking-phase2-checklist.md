- [x] Select flight from public search
- [x] Submit passenger and contact data
- [x] Create booking request and linked order
- [x] Employee endpoint to upload provisional ticket
- [x] Customer can retrieve provisional ticket
- [x] Customer sees agency bank accounts
- [x] Customer uploads payment receipt
- [x] Staff verifies/confirm payment
- [x] Final ticket issuance is blocked until payment confirmation
- [x] Customer can retrieve final ticket
- [ ] Admin dashboard UI for the flight booking queue
- [ ] WhatsApp notifications for each flight status transition
- [ ] Live Trip booking/PNR/ticketing after provider credentials are supplied
