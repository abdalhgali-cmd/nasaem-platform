# F — قرارات تتطلب المالك فقط

لا حاجة لقرار لتوثيق المشكلات أو تشغيل اختبارات اصطناعية أو إنشاء Draft PR. الخيارات التقنية الروتينية تقع ضمن خطة الفريق. القرارات التالية تخص السياسة التجارية/الصلاحيات أو اعتماد نطاق كبير.

| القرار | التوصية المهنية | سبب الحاجة للمالك |
|---|---|---|
| اعتماد نطاق P0 ثم P1 | اعتماد T01/T02 أولًا؛ ثم المسودات والعلاقات والتزامن قبل الشكل | المهمة الحالية تدقيق وتخطيط؛ التنفيذ الكبير يحتاج اعتمادًا منفصلًا |
| تعريف السعر المعروض في QUOTE مقابل FIXED | لا تعرض سعرًا تجريبيًا كالتزام نهائي. حدد متى يصبح السعر نهائيًا ووحدة التحاسب؛ أبقِ القيم الحالية كما هي حتى اعتماد الإطلاق | الكود يميز الوضعين؛ تغيير العرض أو الوضع يؤثر على وعد العميل. لا يحدد المدقق أسعار الإطلاق |
| رفض/تأخر تأشيرة فرد في المجموعة | متابعة الأفراد الناجحين، توثيق سبب وتأخير الفرد الآخر، وعدم إغلاق المجموعة قبل نتيجة معلنة وتسوية سياسة الاسترداد | سياسة الخدمة الجزئية والرسوم والاسترداد قرار تجاري |
| التذاكر المشمولة والإضافية | لا عرض طلب حجز إضافي لباقة تشمل الحجز إلا بتغيير/إضافة واضحة ومعتمدة؛ التأشيرة فقط اختيارية تمامًا | الإتاحة الحالية بعد جميع التأشيرات لا تميز سبب الطلب الإضافي |
| الموظف المكلف مقابل بقية العمليات | إتاحة ملخص الطابور للعمليات، وحصر التعديلات الحساسة بالمكلف/المدير إن وافقت آلية العمل؛ اعتماد الدفع للمحاسب/المدير فقط | التطبيق الحالي يعزل المؤسسة لكنه لا يحصر كل إجراء بالمكلف |
| الاحتفاظ بالجوازات والمسودات والسجلات | مدة صريحة حسب الالتزامات الفعلية، قراءة المسودة تنتهي مع صلاحيتها، حذف مدقق بعد انتهاء الاحتفاظ | التوازن بين حاجة التشغيل والخصوصية والمتطلبات المحلية لا يقرر من اسم حقل في الكود |
| هدف الاستعادة RPO/RTO وإطلاق الإنتاج | تحديد الهدف ثم إثبات استعادة DB+uploads، واختبار الجهاز الحقيقي قبل الإطلاق | له كلفة وتشغيل ومسؤولية عمل؛ لا تكفي اختبارات الكود لاعتماده |

لا يطلب التقرير حساب OCR مدفوعًا أو أسرار إنتاج أو تغيير سعر أو حذف بيانات. التوصية الحالية: عدم إطلاق الخدمة بوصفها مكتملة قبل إغلاق P0 والتحقق المتكامل الموضح في سجل الاختبارات.
