# تنفيذ P0 — الدفعة الأولى

اعتمد المالك خطة التنفيذ في 2026-11-08. هذه الدفعة تعالج كشف رموز المسودات في سجل التطبيق وقراءة المسودات المنتهية؛ لا تعني إكمال الخطة أو اعتماد نشر.

## التغيير

- سجلات HTTP الإنتاجية والتطويرية تنقح مسار المسودة حتى في الطلبات الفاشلة والمسارات المشفرة، وتحذف query وReferer من صيغة السجل. لا يتغير URL الفعلي ولا عقد العملاء الحاليين.
- `getDraftByToken` يمنع إعادة البيانات عند انتهاء الصلاحية، ويعيد controller حالة 410 ورمز EXPIRED. إرسال المسودة المنتهية يُرفض قبل تحقق الخدمة. الرموز غير المعروفة تظل 404، والمسودات الصالحة قابلة للاستعادة.
- استجابة قراءة المسودة تحمل Cache-Control: no-store، بما يشمل أخطاء انتهاء الصلاحية وعدم الوجود.

## الحدود والمتابعة

هذه معالجة التطبيق نفسه؛ إعدادات reverse proxy وسجلات البنية التحتية تحتاج تحققًا عند تجهيز بيئة النشر. نقل الاعتماد من URL إلى header وتخزين hash يحتاجان انتقالًا متوافقًا مع المسودات والعملاء الحاليين، ولم يُنفذا هنا. لا تُغيّر هذه الدفعة بيانات المسودات القائمة أو تحذفها.

T02 الخاص بلقطة التزامات الباقة لم يُنفذ في هذه الدفعة. لا تُستنتج التزامات الطلب القديم من الكتالوج الحالي بوصفها حقيقة تاريخية. تبقى نتائج التدقيق الأصلي في A–F وvalidation سجلًا للمرجع السابق، ولا تُعد شهادة لهذه التغييرات.

## التحقق

على PostgreSQL الاصطناعي المخصص `127.0.0.1:55432/nasaem_umrah_audit`، شُغلت مجموعات draftPrivacy وintakeDrafts وintakeDraftIntegrity وintakeDraftPricing: **16 ناجحًا، صفر فشل**. تغطي الاختبارات الجديدة التقاط سجل Morgan الفعلي في النمطين، والمسودة الصالحة والمنتهية والرمز الخطأ والإرسال بعد الانتهاء وعدم كشف البيانات. تشمل المجموعات القائمة استعادة المسودات ونقل مستنداتها والتسعير والتزامن والملكية.

لم يُجر اختبار جهاز Android أو بيئة حية، ولم يحدث دمج أو نشر أو migration أو تغيير أسعار.
