## استعادة جلسة العمل

تعثر تنزيل Git أولًا ثم اكتمل لاحقًا. نسخة `nasaem-audit` كانت نظيفة عند استئناف العمل، وفيها المرجع أعلاه. `audit-source` خارج هذه النسخة هو تنزيل جزئي لملفات موجودة أصلًا، وليس إعادة كتابة للخدمة. لم تُحذف تلك الملفات أو نسخة `nasaem-review` أو الأرشيف. ملفات npm المؤقتة ليست من مخرجات المراجعة ولا ينبغي تضمينها في commit. فشل المهام المساعدة بسبب حد الاستخدام؛ لا تُنسب إليها مراجعات مكتملة. أُنجزت الأدلة الواردة هنا بفحص مباشر.

## قراءة النتائج

«مثبت بالكود» يعني أن المسار والشرط ظاهران في المرجع المحدد. «مثبت باختبار» يتطلب نتيجة فعلية مسجلة. «خطر يحتاج اختبارًا» ليس ادعاء وقوع حادث إنتاج. «مقترح» لا يعني تغييرًا منفذًا. درجات التقييم تقيس استيفاء الأدلة المتاحة وفق سلم منشور، ولا تمثل نسبة نجاح الاختبارات أو احتمال أمان الإنتاج.
