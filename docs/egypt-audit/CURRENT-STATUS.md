## خطة الإكمال المرتبة

1. توحيد تحقق الجوازات على الخادم لمساري المسودة والإرسال المباشر: وجود كل مسافر، وجواز passport_copy نشط مرتبط بفهرسه، وعدم احتساب ملف مسافر لمصلحة آخر. يُنفّذ قبل إنشاء الطلب/نقل الملفات مع الحفاظ على idempotency والمعاملة والملفات عند الرفض.
2. توحيد حقول المسافر بين التطبيق والموقع وفق المتطلبات المعتمدة، مع مراجعة بيانات OCR بشريًا؛ لا يُعتمد استخراج آلي وحده. قبل فرض الميلاد أو رقم الجواز على الإرسال المباشر، يجب إضافة الحقول ومراجعتها في التطبيق.
3. اختبارات رفض جديدة: صفر جواز، جواز واحد لمسافرين، ملف غير مربوط أو مربوط بمسافر مختلف، بيانات المسافر الثاني الناقصة، تغيير عدد المسافرين بعد الرفع، وإعادة إرسال المسودة بعد استكمال النقص. تبقى اختبارات الدفع والروابط والصلاحيات دون تخفيف.
4. إعداد نوعي الموافقة في QA بالقيم المعتمدة من الإدارة، دون نسخ أسعار أو بيانات إنتاج أو استنتاج أسعار. ثم اختبار Android والويب ولوحة الإدارة: الطلب، الدفع، رفض إيصال وإعادة رفعه، إصدار الموافقة، التذكرة الاختيارية، والتعميم.
5. بعد نجاح الفحص، نشر تجريبي معتمد ومراجعة مستقلة. لا دمج أو نشر إنتاج ضمن تقرير المراجعة هذا.
