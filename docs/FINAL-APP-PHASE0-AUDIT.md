## 4. المخاطر التقنية

1. **سلسلة 10 PRs غير مدمجة:** الفرع الجديد يعتمد عليها؛ إن عُدّلت قبل الدمج سيلزم تحديث الفرع.
2. **لا يوجد جهاز Android ولا SDK في بيئة العمل السحابية:** بناء APK ممكن عبر GitHub Actions أو محليًا إن توفر SDK؛ اختبار الهاتف الفعلي (OTP، رفع الجوازات، الانقطاع) **لا يمكنني تنفيذه ولن أدّعيه**.
3. **OTP واتساب:** يعمل فقط إذا ضُبطت مفاتيح Meta WhatsApp في بيئة الخادم؛ بدونها يرفض الخادم في الإنتاج بـ`OTP_CHANNEL_UNAVAILABLE` (سلوك صحيح).
4. **الطيران:** لا توجد جهة إصدار تذاكر مفعّلة؛ التطبيق يرسل طلب حجز للإدارة فقط ولن يدّعي إصدارًا آليًا.
5. **عزل المؤسسات (Organization):** مطبّق، لكن بعض النماذج المشتركة (Offer/Service) بلا `organizationId` عن قصد.
6. **تكرار مصدر لوحة الإدارة:** `backend/public` هو المصدر و`web/public` نسخة مولّدة بسكربت تحقق منه اختبار.
