# تسجيل العميل باستخدام Google

## الحالة

تكامل الموقع اختياري، ومعطل عند غياب `GOOGLE_CLIENT_ID`. يُستخدم Google Identity Services ومكتبة `google-auth-library` للتحقق الخادمي من التوقيع والصلاحية والجمهور، ثم التحقق من nonce والبريد المتحقق ومعرّف `sub`. جلسة العميل الحالية تستعمل نفسها، بما فيها التجديد والخروج وإبطال الجلسة. لا أسرار في الواجهة أو المستودع.

المراجع الرسمية:
- https://developers.google.com/identity/gsi/web/guides/verify-google-id-token
- https://developers.google.com/identity/protocols/oauth2/policies

## الإعداد بعد اعتماد بيئة الاختبار

1. أنشئ إعداد موافقة OAuth في مشروع Google تملكه الوكالة، وأضف مستخدمي الاختبار خلال الاختبار. لا تطلب صلاحيات خارج openid/profile/email.
2. أنشئ OAuth client من نوع Web application، وأدخل JavaScript origins الفعلية للموقع المحلي وQA؛ لا تستخدم wildcard أو نطاقًا لا تملكه. تدفق GIS callback الحالي لا يحتاج Client Secret داخل الموقع.
3. ضع Client ID في `GOOGLE_CLIENT_ID` على الخادم التجريبي، وفق آلية إعداد الأسرار؛ ليس في Git. طبق migration الإضافية على قاعدة اختبار أولًا. أي تطبيق على قاعدة حية أو إعادة نشر يحتاج موافقة مستقلة.
4. وفّر اتصالًا موثوقًا بين الموقع وAPI؛ nonce يرتبط بملف cookie مؤقت HttpOnly. يفضل API من نفس الموقع لتجنب منع ملفات الارتباط الخارجية. لا تعطل CORS/CSRF أو Secure لتجاوز مشكلة بيئة نشر.
5. افتح صفحة دخول العميل: يظهر زر Google الرسمي فقط عند التهيئة. تحقق من الدخول، ثم تحديث الصفحة وتجديد الجلسة والخروج، وتكرار الدخول دون إنشاء حساب ثانٍ. تحقق من انتهاء التحدي ورفض nonce أو audience خاطئ.

## حدود الحسابات

لا تُربط حسابات CRM أو الحسابات المحلية تلقائيًا بالبريد. إذا وُجد حساب محلي بالبريد نفسه، يعاد 409 مع طلب الدخول بالطريقة الحالية. ربط مزود بحساب قائم يحتاج عملية ربط صريحة بعد إثبات هوية الحساب؛ لم تضف هذه الدفعة ذلك المسار. لا تُختلق أرقام هاتف من Google؛ بيانات التواصل اللازمة تطلب في نموذج الخدمة.

## Android

لا تضع صفحة Google OAuth داخل Capacitor WebView. يلزم إعداد Android OAuth client مع package id وبصمة توقيع النسخة المحددة، تمت إضافة مكوّن Android أصلي باستخدام Credential Manager، ويرسل ID token المرتبط بالـnonce إلى الخادم ثم يحفظ جلسة الوكالة بالمخزن الآمن الموجود. الزر يختفي ما لم يكن المكوّن والإعداد متاحين. يلزم نجاح بناء Android واختبار جهاز فعلي مع إعداد Google قبل إعلان اكتمال الدخول الفعلي. لا توزع مفتاح QA بوصفه توقيع إنتاج.

## الترحيل والتراجع

الترحيل يضيف `Customer.googleSubject` nullable مع unique فقط، ولا يغير حسابات أو كلمات مرور قائمة. أُجري على PostgreSQL اصطناعي محلي. تعطيل التكامل بإزالة Client ID يمنع الدخول الجديد باستخدام Google؛ لا تحذف العمود أو صفوف العملاء تلقائيًا. الرجوع إلى كود قديم لا يقبل جلسات حسابات Google-only، فيستلزم خطة roll-forward أو إبقاء قارئ الجلسات المتوافق.

اختبارات التكامل تستبدل التحقق الخارجي ببديل اصطناعي وتختبر قاعدة البيانات والجلسة الفعليتين؛ لا تعني اختبار Google الحقيقي. اختبار الدخول الفعلي على الجهاز ما زال مطلوبًا.
