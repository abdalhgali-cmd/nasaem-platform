## حدود قياس إمكانية الوصول

الصفحات: `/` و`/umrah` و`/track` و`/contact` و`/admin/login`، على Chromium محلي مع بيانات اصطناعية. أداة axe-core اختبرت قواعد `wcag2a` و`wcag2aa` و`wcag21aa` في الفاتح والداكن بعد انتهاء الانتقالات؛ ليست شهادة توافق شاملة.

- لا تجاوز أفقي عند عرض 360 و390 و768 و1440 بكسل.
- محاكاة تخطيط تكبير 200% بعرض CSS قدره 720 مقابل شاشة 1440: لا تجاوز أفقي. ليست تجربة زر تكبير Chrome على جهاز حقيقي.
- رابط التخطي يعمل بلوحة المفاتيح في الصفحات العامة الأربع. صفحة دخول الإدارة لها غلافها الخاص.
- لم يُختبر قارئ شاشة، ولا هاتف فعلي، ولا كل حالة داخل كل نموذج. تحتاج هذه مراجعة بشرية قبل الإطلاق التجاري.
- أُلغي استنتاج أولي من CSS zoom، لأنه لا يغيّر media queries مثل تكبير المتصفح الحقيقي. وأعيد فحص التباين بعد استقرار تبديل الثيم لتجنب احتساب ألوان أثناء الانتقال.

الدليل الرقمي: [الاستعادة](evidence/restore-2026-11-16.json) و[إمكانية الوصول](evidence/accessibility-2026-11-16.json). لا بيانات عملاء أو مفاتيح توقيع أو أسرار في الدليل.

## الاستعادة الاصطناعية

استُخدمت PostgreSQL 16 على loopback `127.0.0.1:55436` فقط. أُنشئ طلب عمرة فعلي عبر API لمعتمرين ببيانات تخيلية، و3 مستندات أولية وإيصال، واعتمد المحاسب الدفع، وبدأ التنفيذ، ثم نشرت التأشيرتان. بقي الطلب مفتوحًا بعد الأولى وأُغلق بعد الثانية. أرشيف الملفات يتضمن أيضًا PDF إثبات الدفع الصادر.

أُخذ `pg_dump -Fc --no-owner --no-acl` واستُعيد بـ`pg_restore --exit-on-error` إلى قاعدة جديدة؛ أُرشف مجلد المرفقات وأُعيد إلى مجلد مستقل. قارنت أعداد وبصمات JSON لكل جدول، ثم بايتات الملفات المشار إليها، وملكية المعتمر في المستندات والملفات النهائية، وعدد migrations وحالة الطلب والمبلغ. لم تُستخدم نسخة إنتاج أو بيانات حقيقية، ولا يثبت هذا الاختبار RPO/RTO للإنتاج.

## ما يمنع إعلان الإطلاق الكامل

1. **إصدار Android رسمي:** يلزم مفتاح الوكالة و4 أسرار التوقيع وبصمة `ANDROID_RELEASE_CERT_SHA256`؛ لا `keytool` متاح محليًا وقت الفحص. لا يكفي APK QA للتوزيع. الدليل: [ANDROID-RELEASE.md](../ANDROID-RELEASE.md).
2. **اعتماد المحتوى المالي:** الأسعار وحسابات الدفع وأسعار الصرف من المالك. لم تتغير ولم تُعتمد تلقائيًا.
3. **متطلبات تأشيرة العمل:** قائمة الوكالة الفعلية؛ الفحص ينبه عند غيابها، ولا يخترع مستندات.
4. **قناة رموز التتبع:** إعداد مزود واتساب/قناة التسليم واختبار وصول رمز حقيقي. اختبارات المتصفح الاصطناعية لا تثبت التسليم الخارجي.
5. **النطاق الرسمي:** وصول DNS لربطه بالموقع؛ عنوان Railway يعمل، ولا يثبت نجاحه جاهزية النطاق الرسمي.
6. **اختبار هاتف واستعادة إنتاج:** اختبار الجهاز والتوقيع والتحديث، ونسخة مستقلة للمرفقات واستعادة إنتاج فعلية بخطة معتمدة؛ وسياسة الاحتفاظ بالمستندات يحددها المالك.

النشر البرمجي بعد CI لا يحسم هذه المدخلات التشغيلية. تبقى الفنادق مؤجلة وفق القرار السابق.
