# استكمال بيانات تساهيل والتأشيرات — 14 نوفمبر 2026

## التغيير

- تساهيل: بلد تقديم الطلب، مدينة المركز، نوع التأشيرة؛ تاريخ الموعد المفضل اختياري ولا يؤكد الحجز. أسماء المتقدمين إلزامية، دون خطوة رحلة غير لازمة.
- التأشيرات الدولية: دولة الوجهة وبلد تقديم الطلب. هذه أسئلة مراجعة للوكالة وليست قائمة قنصلية موحدة.
- جوازات وصور تأشيرات العمل والتأشيرات الدولية تصبح لكل مسافر في قوائم المتطلبات الجديدة؛ عقود العمل تبقى كما هي.
- الخادم يتحقق من الإجابات المنشورة في الإرسال المباشر وإرسال المسودة قبل إنشاء الطلب. فشل التحقق يبقي المسودة قابلة للاستكمال.
- التطبيق يرفض الإجابات الفارغة والمسافات، مع قبول القيم الصحيحة مثل false و0. الموقع يمنع تجاوز المعلومات الإلزامية.

## قاعدة البيانات والسلامة

Migration: `20261111080000_service_intake_profiles`؛ بيانات إعداد فقط داخل معاملة واحدة، دون تغيير بنية الجداول أو الأسعار أو حالات تفعيل الخدمات أو بيانات العملاء.

تنشئ الأسئلة المفقودة بمعرفات ثابتة، وتحترم الأسئلة الموجودة بأسمائها أو مفاتيحها، بما فيها المعطلة والاختيارية. لا تعيد كتابة لقطات المتطلبات للطلبات القديمة. Seed يستخدم الإعداد نفسه.

اختبار PostgreSQL ينفذ SQL مرتين على جداول TEMP ويتحقق من عدم التكرار، وحفظ الأسعار والإعدادات والمعرفات واللقطات القديمة. أي نشر إنتاجي يحتاج قرار نشر منفصل ونسخة احتياطية؛ الدمج وحده ليس تشغيلًا للـmigration. الاستعادة المفضلة تصحيح للأمام، دون حذف حقول قد تستخدمها طلبات حديثة.
